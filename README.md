## Sobre o projeto

**FlowForge** é um projeto open source em estágio de MVP para criação e gerenciamento de assistentes de atendimento com inteligência artificial.

A plataforma permite configurar chatbots com informações específicas de um negócio, ensinar os assistentes utilizando documentos e incorporá-los em sites por meio de um widget JavaScript.

Este repositório contém exclusivamente o site de apresentação do projeto.

O código-fonte da aplicação, backend, frontend, API, documentação técnica e testes estão no repositório principal:

**[victorH22BR/flowforge](https://github.com/victorH22BR/flowforge)**

## Funcionalidades da plataforma

- Criação e gerenciamento de assistentes.
- Personalização de identidade e instruções.
- Upload de documentos PDF, TXT, MD e CSV.
- Base de conhecimento por assistente.
- Busca lexical e embeddings opcionais.
- Integração com provedores compatíveis com OpenAI.
- Histórico de conversas.
- Widget JavaScript incorporável em sites.
- Configuração de domínios autorizados.
- Interface responsiva.

Consulte o [repositório principal](https://github.com/victorH22BR/flowforge) para conhecer a implementação e o estado atual de cada funcionalidade.
