Cor do widget:

Do zero ao ar em três passos

Nada de fluxograma complicado. Você descreve o negócio, envia os documentos e cola um código no site.

Configure

Defina nome, empresa, instruções, mensagem inicial e a cor que combina com a sua marca.

Ensine

Envie PDF, TXT, MD ou CSV. O assistente responde só com o que está nos seus documentos.

Publique

Autorize os domínios do seu site e cole o snippet. O widget aparece na página.

<!-- exemplo -->
<script src="…/widget.js"
  data-bot="SEU_ID"></script>

O que já funciona hoje

Um MVP completo: painel, API e widget, com testes rodando no CI.

Assistentes

  • Cadastro, login e gerenciamento isolado de assistentes por usuário.
  • Nome, empresa, instruções, mensagem inicial e cor personalizáveis.
  • Teste de conversa no painel, com histórico acessível pela API.

Base de conhecimento

  • Upload de PDF, TXT, MD e CSV com limites de tamanho e de caracteres configuráveis.
  • Busca híbrida: recuperação lexical local mais embeddings opcionais da OpenAI.
  • Sem contexto suficiente, o assistente avisa em vez de inventar a resposta.

Publicação

  • Widget incorporável com um snippet JavaScript.
  • Domínios autorizados por assistente e checklist de publicação.
  • Limites de requisição por IP e por assistente no chat público.

Qualidade e operação

  • Testes de backend (pytest) e frontend (Vitest), integrados ao CI.
  • Migrações Alembic, ambiente de staging e opção com PostgreSQL 16.
  • Logs estruturados em JSON e endpoint interno de métricas.

Transparente sobre o estágio do projeto

O FlowForge é open source e está em MVP: ótimo para desenvolver e demonstrar, ainda não recomendado como SaaS em produção.

Funciona sem chave de IA

Dois modos de resposta

Sem chave, o chat usa busca lexical, responde saudações e mostra os trechos encontrados. Com OPENAI_API_KEY, o RAG combina busca lexical e embeddings, e a lexical continua como fallback se o provedor falhar.

No roadmap

Próximos passos

  • OCR e banco vetorial persistente
  • Fila para processar documentos grandes
  • Confirmação de e-mail e recuperação de senha
  • Políticas de retenção, exportação e exclusão de dados

Rode na sua máquina em um comando

Com Docker instalado, o painel, a API e os dados persistentes sobem juntos. Já tem um café de exemplo pronto para testar.

Guia do usuário Referência da API Arquitetura Roadmap 
# clone e suba tudo
git clone https://github.com/victorH22BR/flowforge.git
cd flowforge
docker compose up --build

# painel  →  http://localhost:5173
# API     →  http://localhost:8000/docs
